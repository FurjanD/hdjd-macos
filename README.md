# HDJD for macOS
A fork of the Linux driver for Hercules DJ consoles, ported for modern macOS (Tested on macOS 26), to bring your old consoles to life.

A port of HDJD for Mac, running with macOS´s CoreMIDI system
Tested on a M1 Pro MacBook Pro, with macOS 26, a Hercules DJ console mk4, and using Mixxx with its default MK4 mappings

All controls work, including the lens
